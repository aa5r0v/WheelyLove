## Златни правила (кратко)

1. **Редактирай кода само локално** (`D:\dev\Wheelylove`), тествай, пращай
   версията чрез release архив. Никога не редактирай файловете на работещия
   контейнер или на VPS-а директно (вж. [14](14-deploy-i-release.md)).
2. **Базата на тестовете винаги е отделна** — името ѝ завършва на `_test`;
   пазачът в `src/lib/test-db-guard.ts` спира сюитата иначе (вж. [13](13-testove-i-proverki.md)).
3. **Секретите не се комитират и не се пишат в документи** — само имена на
   променливи и плейсхолдъри `<LIKE_THIS>` (вж. [11](11-env-promenlivi.md)).
4. **VPS 164.138.216.72 е споделен** с други услуги (QHub на порт 4000, OpenVPN
   tun0). Никога не спирай/трий глобални docker обекти или споделени услуги
   (вж. [14 §9](14-deploy-i-release.md) и [17](17-vps-dostap-adelina.md)).
5. При съмнение виж главата за инциденти ([15](15-incidenti.md)) — повечето
   проблеми имат готов runbook.

> Документацията описва кода така, както е намерен на 2026-10-06, с точни
> позовавания на файл и ред (`файл:ред`). Ако кодът е променен след това,
> позоваванията може да са се изместили — проверявай директно в файла.
